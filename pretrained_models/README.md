# Pretrained models

Model weights are intentionally excluded from version control. The default
configuration expects:

```text
pretrained_models/
├── stable-diffusion-2-1/
├── dinov3_vitb16_pretrain_lvd1689m.pth
└── swinir_real_sr_x4.pth
```

Only this README is tracked. Checkpoint and model-binary extensions are ignored.
